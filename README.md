# OPG Site

A simple website for a family farm (OPG), built with **React** and styled using **Tailwind CSS**.  
The site includes a **blog section powered by Sanity CMS**, where news and updates can be published.  

## Features
- Modern, responsive design  
- Blog functionality with Sanity backend  
- Custom design first created in **Figma** and then implemented in code  

## Tech Stack
- React  
- Tailwind CSS  
- Sanity CMS (backend for blog content)  
- Figma (UI/UX design)  

## About
This project was created to showcase the work of a family farm, combining clean design with practical functionality.
